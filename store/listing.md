# Chrome Web Store Listing - Anti-Spoiler for YouTube

## Name

Anti-Spoiler for YouTube

## Short Description

Hide YouTube durations, progress bars, and previews that can spoil match results.

## Detailed Description

Anti-Spoiler for YouTube helps you watch sports, esports, and other result-sensitive videos without seeing accidental spoilers first.

The extension can hide YouTube time indicators, player progress bars, and preview thumbnails that often reveal how a match or event ends before you start watching.

Features:

- Hide video duration in YouTube lists, search results, recommendations, and the player.
- Hide player and preview progress bars.
- Optionally blur YouTube video previews.
- Turn all protection on or off from a simple popup.
- Keep your settings synced with Chrome profile storage.

Anti-Spoiler for YouTube works locally in your browser. It does not send your YouTube activity, settings, or browsing data to any server.

This extension is not affiliated with, endorsed by, or sponsored by YouTube or Google.
