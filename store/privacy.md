# Privacy Policy - Anti-Spoiler for YouTube

Anti-Spoiler for YouTube is designed to work locally in your browser.

## Data Collection

The extension does not collect, sell, transfer, or transmit personal data.

The extension stores only its user-selected settings, such as whether protection is enabled and which YouTube elements should be hidden. These settings are stored using Chrome's `chrome.storage.sync` API so they can persist across browser sessions and sync with the user's Chrome profile when Chrome Sync is enabled.

## YouTube Page Access

The extension runs only on `https://www.youtube.com/*`. It uses this access to hide or blur spoiler-prone interface elements on YouTube pages, including durations, progress bars, and video previews.

The extension does not send YouTube page content, browsing history, video titles, URLs, watch activity, or account information to the developer or to any third party.

## Remote Code

The extension does not load or execute remotely hosted code.

## Third Parties

The extension does not share user data with third parties.

## Advertising

The extension does not show ads and does not use user data for advertising.

## Limited Use Statement

The extension's use of information is limited to providing and improving its single purpose: hiding spoiler-prone YouTube interface elements in the user's browser. The extension does not transfer, sell, or use user data for unrelated purposes.
