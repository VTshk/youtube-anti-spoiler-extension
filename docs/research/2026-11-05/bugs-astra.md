## Проверено, нарушений нет

- `hideTime` обязателен, legacy-ключи игнорируются и удаляются после успешной записи.
- Manifest: только `storage` и `www.youtube.com`, Chrome 111+, порядок MAIN/isolated-скриптов верный.
- Патч history в MAIN world сохраняет this/аргументы/результат.
- Повторный монтаж overlay на heartbeat есть; pause-lock, таймеры, ResizeObserver снимаются при teardown.
- Исходное `muted` восстанавливается; заглушённое пользователем видео не размучивается.
- Чат-гард не включается на подтверждённом VOD; «Show comments» сбрасывается при смене ID.
- Popup read-only при ошибке первоначального чтения.
- Мост не делает eval/HTML-вставку и не даёт странице привилегированных операций.

## Не проверено / вопросы

- Живой браузер недоступен (занят профиль chrome-devtools).
- `document.title` и `navigator.mediaSession` (название и позиция в панели Chrome/ОС) не обрабатываются вовсе — фактическое поведение не проверено; README сужает опцию названий до списков/рекомендаций/end cards.
- Shorts, строка информации miniplayer, главы, UI клавиатурной перемотки — тесты проверяют наличие строк-селекторов, не совпадение с живым DOM.
- Премьеры, запланированные эфиры, эфир, начавшийся после прекращения опроса — нужны реальные player responses.
- Канал MAIN↔isolated не аутентифицирован (страница может подделать live-state CustomEvent, requestId не сверяется), но page-script и так управляет DOM и media element — самостоятельной уязвимостью не считается.
