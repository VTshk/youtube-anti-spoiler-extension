## Не проверено

- Настоящие системные медиаконтролы (меню медиа Chrome, оверлей Windows) — проверен только объект `navigator.mediaSession` на странице; позицию, которую Chrome берёт прямо из `<video>`, расширение убрать не может (записано в README).
- Настоящий мини-плеер с эфиром, реклама перед эфиром, полноэкранный режим эфира, `/@channel/live` — как и в порции 2 (в headless не воспроизводятся).
- Узкая вёрстка, где комментарии открываются панелью из тизера; комментарии Shorts — не покрыты (см. вопросы).
- Горячая клавиша в настоящем Chrome — только unit-тесты (в headless `commands` не нажать).
- Визуально кнопки F2 проверены на одном кадре; на ярком видео белый текст без подложки может читаться хуже.
